# Quản lý nhà trọ

Bài tập lớn cuối kỳ Lập trình Web. Đề 4: Quản lý nhà trọ.

## Công nghệ
React (Vite), React Router, Redux Toolkit, Tailwind, Node.js, Express, MongoDB.

## Cài đặt

### Server
```bash
cd server
npm install
cp .env.example .env
# rồi điền giá trị thật
npm run dev
```

### Client
```bash
cd client
npm install
cp .env.example .env
npm run dev
```
